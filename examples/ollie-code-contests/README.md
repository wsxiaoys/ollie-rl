# Ollie CodeContests — Harbor + ollie-rl

This standalone example trains the host-local **Ollie agent** on the
`open-thoughts/CodeContests` Harbor tasks. Ollie works in its local/delegated
workspace, while Harbor runs verification in a separate container environment.

The implementation is intentionally separate from `examples/code-contests`:
its data preparation and training drivers are duplicated so either example can
change without coupling to the other.

```
examples/ollie-code-contests/
├── prepare_data.py
├── run_training.py
├── tasks/              # generated Ollie-adapted Harbor tasks
└── trials/             # generated Harbor trial output
```

## Prepare tasks

From the repository root:

```bash
uv run python examples/ollie-code-contests/prepare_data.py --limit 64
```

The preparation script extracts each dataset tarball and then configures the
Harbor task with:

- `artifacts = ["/app"]`, so the Ollie workspace reaches the verifier;
- `environment.workdir = "/app"`;
- `verifier.environment_mode = "separate"`;
- `verifier.environment.docker_image = "python:3.12-slim"`, so Harbor can
  create the separate verifier and upload the task's tests to it.

Tasks prepared by an older version can be updated without downloading them
again:

```bash
uv run python examples/ollie-code-contests/prepare_data.py --repair-existing
```

## Run training

Start the ollie-rl server first (`uv run poe dev`), then run:

```bash
uv run python examples/ollie-code-contests/run_training.py \
  --verifier-environment daytona \
  --runs 200 \
  --concurrency 8
```

Each Ollie invocation receives a run-specific endpoint:

```
http://<ollie-host>/tuners/<tuner-id>/runs/<run-id>/openai/v1
```

This attributes every completion to its dispensed run. The standard Harbor
verifier receives `/app` in a separate environment and reports the task reward.

### Useful flags

| Flag | Default | Meaning |
|---|---|---|
| `--base-url` | `http://localhost:8000` | ollie-rl API URL. |
| `--recipe` | `grpo_16x32` | Tuning recipe. |
| `--trainer` | `fake` | Trainer factory. |
| `--agent-model` | `openai/ollie` | Provider/model passed to OllieAgent. |
| `--ollie-executor` | `daytona` | Delegated executor: `none`, `local`, or `daytona`. |
| `--ollie-max-steps` | unset | Optional model/tool step limit. |
| `--ollie-command-timeout-ms` | unset | Optional delegated-command timeout. |
| `--verifier-environment` | `docker` | Separate Harbor verifier backend (`--environment` is a compatibility alias). |
| `--runs` | `200` | Number of run/score iterations. |
| `--concurrency` | `8` | Parallel Harbor trials. |
| `--tuner-id` | unset | Resume an existing tuner. |

The task directories generated by this example are independent from those under
`examples/code-contests/tasks`; do not mix unadapted tasks into this example.
